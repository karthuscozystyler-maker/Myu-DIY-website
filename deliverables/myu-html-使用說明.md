# 沐幕引磁收納DIY：SHOPLINE 短HTML使用說明

## 功能

- **21款引磁布**：每款可選 38×70 cm 或 70×100 cm，並可橫放／直放；布款面板可搜尋及按「花紋／素色」篩選。
- **25款配件**：24款配件連同圓形小鐵盒（每盒4入）。每款都有米白（we）及岩嶺暗灰（BK）資料；小鐵盒按四入整盒計算。
- 配件按玄關、廚房、浴室、書檯／化妝檯分類；手機每頁最多顯示4款，桌面保留左側選配欄。
- 「購買清單」在手機和電腦都會於畫面中央彈出。

## 加入購物車狀態

DIY加車清單先列配件、再列引磁布；小鐵盒按整盒向上取整，例如排5個會加入2盒（共8個），並顯示3個未排位。

引磁布及套裝尚未在SHOPLINE建立，因此涉及未上架商品的清單會在**任何加車前停止**並提示未開放購買，不會假顯示成功。

## 貼入SHOPLINE的方法

1. 先確認 GitHub Pages 已開啟（見 repo 的 `GITHUB-UPLOAD-README.md`），並可打開 `https://karthuscozystyler-maker.github.io/Myu-DIY-website/`。
2. 在SHOPLINE原本的HTML元件中，刪除舊短碼。
3. 開啟 `myu-shopline-cart-ready.html`，複製**全部內容**貼入，再儲存。
4. 重新整理預覽，依次測試首頁、四個系列、DIY、選布、加入一件配件及打開「購買清單」。
5. 不要把舊短碼和新短碼同時保留，以免載入兩次。

短HTML只是一小段載入碼；完整程式、樣式及圖片由 GitHub Pages 載入，不會觸發「頁面內容資料量過大」。元件使用 Shadow DOM 獨立容器，不影響原店樣式，內部換頁不依賴網址或 hash。之後更新程式只需 push 到 GitHub，毋須重新貼碼。

## 已知限制

- 「自由調節收納架」未有可驗證的正面寬度，只顯示在目錄，暫不允許排上布。
- 參考價格來自公開商品資料；最終價格、庫存及可購狀態以SHOPLINE購物車為準。
